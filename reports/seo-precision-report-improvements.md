## 검증 결과

- 엔진 및 공통 UI TypeScript 검사 통과.
- 전체 149개 테스트 파일, 1,779개 테스트 통과.
- CLI·웹·Electron 프로덕션 빌드 통과. Electron 창 실행 검증은 포함하지 않는다.
- 규칙 373개·카테고리 20개 및 디자인 토큰 동기화 검사 통과.
- 실제 `https://example.com` CLI 검사: 373개 규칙 실행, 실행 예외 0건, 점수 모델 7·결과 스키마 4 확인.
- Chromium: 2초 뒤 주입된 본문 1,759자를 읽고 JS 의존성을 감지했다. 끝까지 비어 있는 앱은 미측정이며, 빈 본문에 근거한 점수 상한을 적용하지 않았다.
- Chromium 크롤링: 렌더링 링크·사이트맵 URL 수집, 3개 페이지의 모바일 본문 손실 감지, 응답 크기 계측을 확인했다.
- 1,000페이지 리포트의 HTML 5MB·LLM 250KB·Markdown 1MB 크기 예산 검사 통과.

## 해석 범위

- 점수 모델은 **7**, 결과 스키마는 **4**다. 규칙 ID와 카테고리 가중치는 유지하지만, 오판 보정·미측정 처리·중복 그룹의 대칭 판정으로 점수가 달라질 수 있다. 과거 점수는 재계산하지 않는다.
- 렌더링 준비도는 제한 시간 안의 관측이다. 모든 비동기 작업의 완료나 검색엔진의 실제 색인 여부를 보장하지 않는다.
- 유사도는 표본 추정이다. 그룹은 연결 관계로 묶이므로 모든 구성원이 서로 동일한 유사도를 갖는 것은 아니다. 대표 URL은 표시용이며 권장 canonical이 아니다.
- 저장 리포트는 정확한 집계와 대표 근거를 제공한다. URL·그룹 목록은 표본 크기를 제한하고 전체 개수를 함께 기록한다.
- confidence가 없는 과거 결과를 관측 확정으로 바꾸지 않는다. 이 필드는 이번에 보정한 진단부터 적용하며, 기존 모든 규칙의 판단 신뢰도를 소급 검증한 것은 아니다.
